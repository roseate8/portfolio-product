# Antigravity Rules & Guidelines

## End of Conversation Protocol: Substantial Commits

At the end of each session, follow these steps for **substantial** updates (completed features, bug fixes, or structural changes):

1.  **Commit Locally**: Use `git add` and `git commit -m "[message]"` on the active branch. Do **not** commit minor tweaks or incomplete work.
2.  **No Pushing**: Keep changes local for manual review.
3.  **Notify**: Briefly confirm the commit and summarize the changes in your final message.
